# Задание 2. Подготовка базы знаний

## Исходная предметная область

Для подготовки базы знаний была выбрана вселенная Star Wars на основе открытых страниц fandom-энциклопедии.

## Что было сделано

1. Отобрано 30+ страниц по ключевым сущностям: персонажи, локации, технологии, организации и события.
2. С помощью Python-скрипта страницы были скачаны и очищены от HTML-разметки, навигационных блоков и лишнего форматирования.
3. Каждый документ был сохранён отдельно по принципу: один файл = одна сущность.
4. Был подготовлен словарь замен `terms_map.json`, в котором исходные названия сущностей заменены на вымышленные.
5. После замены терминов была сформирована итоговая папка `knowledge_base/` с уникальными документами.

## Логика замены

Цель замены — сделать тексты непредсказуемыми для LLM, чтобы модель не могла отвечать по памяти и была вынуждена опираться на retrieval.
Заменялись:

- персонажи;
- планеты;
- организации;
- технологии;
- концепции мира;
- события.

Примеры:

- Darth Vader → Xarn Velgor
- Death Star → Void Core
- The Force → Synth Flux

## Результат

Сформирована уникальная база знаний из 30+ документов, которая сохраняет внутреннюю логику исходного мира, но больше не распознаётся как Star Wars.
Эта база может использоваться для дальнейшей честной проверки RAG-пайплайна.
