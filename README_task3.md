# Задание 3. Создание векторного индекса базы знаний

## Использованная модель эмбеддингов

Для построения векторного индекса была использована модель:

**sentence-transformers/all-MiniLM-L6-v2**

- Тип: локальная embedding-модель
- Размер эмбеддингов: 384
- Библиотека: sentence-transformers
- Запуск: локально на CPU

Данная модель была выбрана как оптимальный компромисс между скоростью, качеством и требованиями к ресурсам.

---

## Использованная база знаний

Для индексации использовалась база знаний из задания 2:

- Папка: `knowledge_base/`
- Количество документов: **31**
- Тематика: вымышленная вселенная на основе переработанной Star Wars
- Все ключевые термины заменены (Xarn Velgor, Void Core, Synth Flux и др.)

Это гарантирует честную работу механизма RAG.

---

## Чанкинг документов

Документы разбивались на чанки с помощью:

`RecursiveCharacterTextSplitter`

Параметры:

- Размер чанка: **1200 символов**
- Перекрытие: **200 символов**

Итог:

- Всего чанков: **1325**

Для каждого чанка сохранялись метаданные:

- source (путь к файлу)
- doc_id
- title
- chunk_index
- chunk_id
- start_char
- end_char

---

## Построение векторного индекса

Для хранения эмбеддингов использована:

**FAISS**

Процесс:

1. Тексты → чанки
2. Чанки → эмбеддинги
3. Эмбеддинги → FAISS индекс

Сохранённые артефакты:

- artifacts/index/faiss.index
- artifacts/index/chunks.jsonl
- artifacts/index/manifest.json
